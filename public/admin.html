Trazer os dados do arquivo antigo

Os lançamentos feitos no arquivo HTML antigo ficaram salvos só no navegador de quem usou. Para trazer esses dados para cá, no computador onde o arquivo foi usado:

  1. Abra o arquivo gestao-de-obra-bordero.html antigo no mesmo navegador de sempre.
  2. Aperte F12, clique na aba Console, cole a linha abaixo e aperte Enter. O conteúdo vai para a área de transferência.
  3. Volte aqui, cole no campo e clique em Importar.

copy(JSON.stringify({rows:JSON.parse(localStorage.getItem("bordero_v2")),areas:JSON.parse(localStorage.getItem("bordero_v2ar")||"null")}))
